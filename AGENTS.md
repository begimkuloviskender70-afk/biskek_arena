# Bishkek Arena

Командная CS2-платформа для Бишкека. Общайся с владельцем по-русски. Эта папка — корень существующего проекта; продолжай работу здесь.

Перед изменениями прочитай PROJECT_PLAN.md (идея, функции, архитектура, этапы и контекст), IMPLEMENTATION.md (состояние реализации) и package.json. Реализация: Vinext/React/TypeScript, Cloudflare Workers, D1, Drizzle. Интерфейс: app/page.tsx и app/globals.css. Доменные правила: lib/league.ts. Steam-вход: lib/auth.ts и lib/steam-openid.ts.

Есть команды, приглашения, вызовы, Steam OpenID, необязательное получение FACEIT-данных и отдельный демонстрационный режим. Реальные игровые серверы не подключены. FACEIT OAuth и Anti-Cheat не реализованы. Не представляй демонстрационные матчи как реальные.

Сайт уже зарегистрирован в Sites: используй существующий .openai/hosting.json, не создавай повторную регистрацию. На момент передачи контекста 7 октября 2026 года успешная публикация не подтверждена. Перед сообщением о доступности проверь текущий статус. Финальную сборку интерфейса и полный пользовательский сценарий ещё нужно проверить. Ранее прошли 22 серверных теста; полноценный вход пользователя через Steam не проверен.

Для запуска нужен Node.js 24. Команды запуска, миграции и тестов описаны в IMPLEMENTATION.md. Локальная миграция уже применялась: сначала проверь состояние базы. Не коммить ключи, .dev.vars, сессии и данные локальной базы. Обновляй IMPLEMENTATION.md после существенных изменений, чтобы новые чаты могли продолжать работу.
